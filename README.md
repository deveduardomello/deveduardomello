Olá, Eu sou <strong>Eduardo Mello!</strong>

Com foco em Java, gosto de resolver problemas reais transformando regras de negócio em sistemas que funcionam de verdade no dia a dia. Para mim, a melhor parte da programação é investigar gargalos, estruturar soluções e ver o código rodando na prática para facilitar a rotina das pessoas.

Atuo no desenvolvimento de aplicações e APIs RESTful com Java, Spring Boot, Spring Security, JWT, Spring Data JPA / Hibernate e bancos de dados como MySQL. Tenho atenção à arquitetura, separação de responsabilidades e código limpo para construir sistemas seguros, confiáveis e fáceis de manter. Também tenho domínio de HTML, CSS e JavaScript, utilizando IA de forma estratégica para acelerar entregas, fazendo ajustes manualmente no front-end quando necessário.

Minha trajetória não começou no código: sou formado em Ciências Contábeis pela Anhanguera e empreendi à frente de uma agência de marketing digital. Essa vivência me deu uma forte visão de negócios, processos, atendimento ao cliente e gestão. Com o tempo, percebi que meu maior entusiasmo estava nos bastidores técnicos, construindo ferramentas internas — o que me motivou a direcionar minha carreira 100% para o desenvolvimento backend.

Alguns projetos e entregas que marcam minha trajetória até aqui:

Sistema de CRM estilo Kanban: Desenvolvi do zero uma aplicação web com quadro Kanban (drag and drop) para organizar a prospecção de clientes da minha agência. Construído com Java, Spring Boot, Thymeleaf e MySQL, o sistema roda hoje em produção no meu próprio servidor caseiro (ZimaOS), atendendo a operação real junto a outros serviços self-hosted.

Plataforma de Delivery (Simulação iFood): Desenvolvimento de sistema completo com controle de acesso e perfis distintos (restaurante e cliente), aplicando autenticação e autorização com Spring Security e JWT, além de persistência de dados com JPA/Hibernate.

Projetos Web: Criação e estruturação de diversas landing pages com arquitetura modular e código organizado para clientes reais.

Atualmente, aprofundo meus estudos em Java, APIs RESTful, Microsserviços e programação reativa (Spring WebFlux) pela Rocketseat, buscando evolução constante e preparando terreno para retomar minha graduação na área de Engenharia de Software.

Hoje busco minha oportunidade para atuar como Desenvolvedor Backend Java, contribuindo com um time colaborativo onde eu possa unir minha maturidade profissional e visão de negócio à minha paixão por resolver problemas.

### CRM Kanban Renovo OS
Desenvolvi este CRM Kanban (drag and drop) para centralizar e organizar a prospecção comercial da agência Renovo.

• Java & Spring Boot: escolhidos pela robustez nas regras de negócio.
• Spring Data JPA & MySQL: agilidade no CRUD e integridade dos dados.
• Thymeleaf & JS: reaproveitamento de layout e fluidez visual sem frameworks pesados.
• ZimaOS & Docker: deploy em servidor self-hosted para operação contínua em container Docker a custo zero.

Usei IA como copiloto para acelerar o front-end, dirigindo a arquitetura e revisando o código manualmente.

### iFome
Sistema inspirado no **Ifood**, desenvolvimento dos protótipos de tela em HTML, CSS e Javascript. Backend criado em Java com Spring boot como framewwork para potencializar o desenvolvimento, segurança feita com a utilização de token JWT. Após a conclusão do Backend, o Frontend foi recriado utilizando um framework chamado thymeleaf.
